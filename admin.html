⚙️ Firebase Firestore 보안 규칙 설정 안내

Firebase Firestore의 기본 설정은 보안을 위해 외부 읽기/쓰기가 차단되어 있습니다.
모든 방문자의 신청서가 정상적으로 누적되도록 아래 규칙을 복사하여 적용해주세요.

1. Firebase 콘솔 Firestore 규칙 탭 바로가기 ↗
2. [규칙(Rules)] 편집기에 아래 코드를 붙여넣고 [게시(Publish)] 클릭: 
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /applications/{docId} {
      allow read, write: if true;
    }
    match /agreements/{docId} {
      allow read, write: if true;
    }
  }
}
복사되었습니다!
